# Code Geass-inspired wrap — 2023 Tesla Model 3

This working concept is for a **2017–2023 / pre-refresh Model 3**, using the repo's existing `model3/template.png`.

## Direction: ZERO REQUIEM

A dark, premium anime-inspired treatment instead of a poster pasted over the car:

- **Base:** near-black / deep indigo
- **Primary energy:** crimson red
- **Accent:** metallic imperial gold
- **Secondary:** royal violet
- **Motifs:** stylized Geass-eye geometry, chess-grid strategy lines, Zero-inspired angular mask language, asymmetric motion streaks
- **Goal:** recognizable to a Code Geass fan while still looking clean on a Tesla

## Files

- `builder.html` — browser-based 1024×1024 wrap generator using the official Tesla Model 3 template already in this repo.
- It exports `Code_Geass_Zero.png`.

## Tesla Paint Shop requirements

- PNG
- 1024×1024
- Under 1 MB
- Filename <= 30 characters using letters, numbers, spaces, dashes, or underscores
- 2023 Model 3 uses the classic `model3` template, not the 2024+ folders.

## Next art pass

The builder intentionally starts with original graphic motifs rather than copied anime frames. A later pass can add a user-supplied Lelouch/Zero/C.C. image to specific side panels if desired.
